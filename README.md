This repository contains four Solidity smart contract tasks demonstrating fundamental concepts in blockchain and decentralized application development. Task 1 implements a basic custom ERC20-like token called Mango Token (MA) with manual balance tracking and transfer functionality. Task 2 builds a standard ERC20 token named MangoCoin (MNG) using the OpenZeppelin library to follow industry best practices. Task 3 introduces a simple decentralized lending protocol that allows users to deposit ETH, borrow against collateral, repay loans, and withdraw funds. Task 4 presents a refined version of the lending contract with improved structure and clarity. These tasks collectively showcase understanding of Solidity fundamentals, token standards, contract inheritance, payable functions, mappings, events, and basic DeFi lending logic. This project is built using Solidity ^0.8.0 and is intended for educational and learning purposes in blockchain development.
